## 先确认可选模板

在微信公众平台的订阅消息中查找“到期”“事项提醒”“服务提醒”等与设备保修提醒用途相符的模板。请记录最接近的 1–3 个模板标题、可选字段名称及类型；能看到字段编号时可一并记录，不需要 AppSecret、OPENID 或其他凭据。

服务端支持一次性模板：标题含“保修/到期”或为“待办事项提醒”，名称字段为设备/物品/商品或提醒内容的 thing 类型，到期字段为 date/time 类型；额外字段支持 thing/phrase 提示，以及明确标注为提醒时间/日期的 time/date。提醒内容写设备及保修事项；time 型到期日期写保修结束日北京时间 23:59，提醒时间写实际发送北京时间。字段编号从微信真实模板读取，不硬编码模板 ID。

## 无可用模板时的申请草稿

如果后台提供申请新模板入口，可按实际服务类目填写以下内容。是否批准、字段类型及模板编号以微信返回为准，申请期间提醒入口继续保持未配置态。

| 项目             | 建议填写                                                                                                                 |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 模板标题         | 保修到期提醒                                                                                                             |
| 订阅类型         | 一次性订阅                                                                                                               |
| 设备名称         | 短文本（thing）；示例：示例设备                                                                                          |
| 保修到期日期     | 日期（date）或时间（time）；示例：2026-12-31                                                                             |
| 温馨提示（可选） | 短文本（thing）；示例：请及时查看设备保修状态                                                                            |
| 服务场景         | 用户在个人设备台账中主动选择一台本人设备和提醒日期，并授权接收一次保修到期提醒。仅发送设备名称、保修到期日期和必要提示。 |
| 触发条件         | 用户主动订阅后，在其选择的日期到达时发送一次；拒绝不创建任务，可取消未发送任务，删除设备或注销时取消计划。               |

以上均为合成示例。字段编号由微信生成，无需自行假定 thing1/date2；批准后以实际模板字段为准核对映射。如果后台不提供相应类目或申请入口，记录该限制，保持未配置态，不能用无关业务模板替代。

## 启用与验证

1. 将批准或确认兼容的模板添加到本小程序账号。
2. 回到设备详情 → 保修提醒刷新，服务端模板查询缓存最长约一分钟。
3. 本人在小程序中主动点击“授权并设置一次提醒”，选择明天至保修到期之间的日期。检查待发记录和取消操作；拒绝授权时不能创建计划。
4. 到计划日期实际接收并打开提醒后，再记录真实消息验收结果。模板已添加、已授权、任务已建立和实际已送达分别记录。

公众平台受当前浏览器访问策略限制，模板添加/申请需要本人操作；现有其他四项功能可以先体验。
