## 2. 小程序基础配置

### 2.1 注册与主体

- 确认小程序主体类型：个人主体或非个人主体
- 确认管理员、开发者、体验者权限
- 确认小程序名称、头像、简介与 GearFlow 功能一致
- 确认服务类目符合实际功能

### 2.2 类目判断

GearFlow 属于个人设备信息管理工具，不涉及：

- 社交
- 交易
- 支付
- 电商
- 金融
- 医疗

提审前必须在官方“开放的服务类目”文档中确认个人主体可选类目，并按实际功能选择。

### 2.3 CloudBase 与小程序绑定

当前阶段不规划自有 API 域名、独立服务器、Nginx 或自维护 HTTPS 证书。发布前需要确认：

- CloudBase 环境与当前微信小程序 AppID 正确绑定
- 前端只保存 CloudBase 环境 ID 等公开配置
- 微信 AppSecret、CloudBase 管理凭据和服务端密钥不出现在客户端代码
- 如平台要求配置合法域名，按 CloudBase 和微信官方文档当时给出的域名清单执行
- 开发数据与生产数据隔离

当前登录路由与数据网关不是同一域名，须同时核对 request 合法域名；准确地址见 `docs/OPS7-LOGIN-DESIGN.md`。正式构建使用 `pnpm build:mp-weixin:release`，产物 `setting.urlCheck` 必须为 `true`。普通构建保留开发调试配置，不能作为提审已核验的凭据。

不自行购买 VPS，不自行部署 MySQL / PostgreSQL，不自行维护 Nginx。

## 3. 备案

根据官方《小程序备案操作指引》：

- 在中国大陆提供非经营性互联网信息服务需依法履行备案手续
- 小程序后台提供备案入口
- 备案前需准备主体、负责人、小程序信息及相关材料
- 涉及特定前置审批类业务时需提交对应审批文件

GearFlow 目标：

- 非经营性个人工具
- 不做交易、支付、社区和信息服务发布
- 不设计需要前置审批的功能

上线前必须确认：

- 当前是否必须完成备案后才能上架
- 个人主体备案材料
- 小程序服务内容描述
- 工信部短信核验流程
- 备案状态

## 4. 隐私与用户协议

### 4.1 必须提供

- 《用户协议》
- 《用户隐私保护指引》或隐私政策
- 账号注销入口
- 用户数据删除能力

### 4.2 最小化收集

GearFlow 收集：

| 数据                   | 是否必需     | 用途                                                     |
| ---------------------- | ------------ | -------------------------------------------------------- |
| CloudBase 用户身份标识 | 必需         | 账号识别与数据隔离                                       |
| 微信 OpenID            | 登录交换所需 | 服务端 code2session 与自定义票据身份处理，不单独返回前端 |
| 设备名称、分类         | 必需         | 资产管理                                                 |
| 购买日期、价格         | 可选         | 成本统计                                                 |
| 保修日期               | 可选         | 状态计算和提醒                                           |
| 维护记录               | 可选         | 生命周期管理                                             |
| 序列号                 | 可选         | 报修辅助，默认提示非必需                                 |
| 昵称、头像             | 可选         | 展示，可以不提供                                         |
| 设备照片、发票         | P1 再收集    | 凭证管理，MVP 不做                                       |

### 4.3 隐私声明必须覆盖

如果 MVP 使用微信登录 / CloudBase 身份认证，必须声明：

1. 收集用户登录标识
2. 收集目的
3. 使用范围
4. 保存期限
5. 用户查询、更正、删除数据的方式
6. 账号注销方式
7. 开发者联系方式

当前协议版本为 `1.0.1`（2026-09-23），说明可选序列号用途、保存期限、软删除与账号注销、技术服务方、本机导出及已分享副本的边界。普通登录恢复不记录同意，新版协议须用户明确确认。“我的”和协议页提供微信原生意见反馈入口；平台后台隐私声明与开发者联系信息仍需提审前人工核对。

如果后续启用图片上传、订阅消息或 AI，必须重新更新隐私声明，并保证声明与实际接口调用一致。

### 4.4 敏感数据规则

- 序列号、发票、照片默认不强制填写
- 日志禁止输出敏感数据
- 附件访问必须通过 CloudBase 云存储权限或临时访问能力授权
- 附件访问必须校验用户归属
- AI 服务启用前必须单独评估第三方数据流转

## 5. 账号注销与数据删除

小程序内必须提供可见入口，不能只放在文档中。

流程：

```text
我的
→ 账号注销
→ 展示影响范围
→ 二次确认
→ 删除用户数据
→ 退出登录
```

必须删除：

- 用户资料
- 设备
- 保修
- 维护记录
- 时间线
- 统计成本
- 附件及 CloudBase 云存储文件
- 同意记录中的可识别信息
- GearFlow 客户端登录态和本地缓存

当前未启用附件云存储。已有 CSV 导出应在分享完成/取消/失败后删除本机临时文件，退出和注销再次清理；已主动分享至微信聊天或其他应用的副本不属于本应用可删除范围。云端删除成功而本机退出失败时，提示必须区分这两个结果。

## 6. 用户身份

当前使用 `wx-login` 云函数完成微信 code2session 并签发 CloudBase 自定义票据，后续会话由 CloudBase SDK 管理，不自建 access/refresh JWT 服务。

核心流程：

```text
用户明确确认当前协议
→ uni.login → 公网 wx-login（服务端 AppSecret + 自定义登录私钥）
→ CloudBase SDK 交换票据、建立身份会话
→ PostgreSQL RPC 从 auth.uid() 创建用户并记录显式同意
→ RLS 与受保护 RPC 限制用户只能访问自己的数据
```

普通恢复只读已有用户，不重复写同意。AppSecret 与登录私钥曾暴露的轮换事项仍待确认；重置必须同步函数配置并核验既有用户的数据归属。

安全要求：

- AppSecret 和 CloudBase 管理凭据只能保存在服务端或平台配置中
- 不把 AppSecret 打包进小程序
- 不向客户端返回 OpenID 或管理凭据
- `userId` 必须由可信身份上下文派生，客户端不能传入
- 账号注销后 GearFlow 业务数据不可访问，云存储文件同步删除
- 平台身份生命周期按 CloudBase 与微信官方规则处理

## 7. 订阅消息

MVP 不实现订阅消息。P1 用于保修到期提醒。

启用前必须：

1. 在小程序后台申请或选择合适模板
2. 用户主动触发授权
3. 不诱导、不强制授权
4. 明确提醒内容和频率
5. 更新隐私政策
6. 核实最新官方订阅消息规则

## 8. 图片与附件

MVP 不实现图片上传。

P1 启用前必须：

- 限制文件类型和大小
- 使用 CloudBase 云存储，数据库只保存文件引用和元数据
- 服务端生成随机云存储路径
- 不信任原始文件名
- 校验 MIME 和文件内容
- 访问必须经过 CloudBase 云存储权限或临时访问授权
- 删除设备和账号时删除文件
- 在隐私政策中说明用途和保存期限

## 9. 审核风险与规避

| 风险                 | 规避方式                                      |
| -------------------- | --------------------------------------------- |
| 功能空白或 Demo 化   | 提审前完整实现核心流程                        |
| 类目不符             | 只保留设备管理工具功能                        |
| 隐私声明与接口不一致 | 提审前核对接口调用                            |
| 登录强制             | 静态介绍页可浏览                              |
| 账号注销不可用       | 提审前真机验证                                |
| CloudBase 环境不可用 | 检查小程序 AppID 绑定、环境状态和平台域名要求 |
| 诱导授权             | 订阅消息延后且用户主动触发                    |
| 数据删除争议         | 后端真实删除，不做假删除                      |
| 内容审核风险         | 不提供社区、发布、分享 UGC                    |
