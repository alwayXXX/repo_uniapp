# Phase 11 自用功能迭代

## 范围与验收

2026-10-27 用户明确授权「P11 按清单逐项做完」。本次依次实现设备处置、年度设备报告、JSON 导出、照片/发票附件和保修到期订阅提醒；保留已有 CSV，不进入 AI。

- 处置：出售/报废日期、收入和备注，更新状态并追加不含原值的时间线；收入独立展示，不改变原购买/维护统计。
- 年报：按自然年汇总购买、维护、处置收入与月度变化；仅统计当前保留且未软删除设备，不宣称重建已删除数据或历史年末快照。人民币整数分，支持合法历史年度与无数据。
- JSON：导出本人未删除设备及关联维护、保修、处置信息，剔除身份和云文件地址。复用本机文件分享/清理，不包含附件二进制，不实现导入恢复。
- 附件：每设备最多 10 个，每文件最多 2 MiB，JPEG/PNG/WebP/PDF；后端校验文件头、大小和设备归属，随机云路径，客户端不能任意指定 fileID。预览经鉴权云函数读取文件内容，以兼容微信域名校验；本机专用预览目录在应用再次显示、页面刷新和退出时清理。删除附件、设备和账号均先清理云文件，再清理元数据，失败可重试。
- 提醒：用户主动选择设备和日期，点击一次性订阅授权，拒绝不创建任务。平台模板未就绪时展示未配置态。定时任务条件更新领取，避免重复发送；取消、删除设备和注销均撤销未发送任务。发送结果不明不自动重发。

## 架构、API 与数据

沿用 `gearflow-api` Event Function、Nodejs18.15、可信 OPENID 与 CloudBase MySQL。新增 `device_attachments`、`device_reminders`；设备现有处置日期/金额字段复用，处置说明写入独立 `disposal_notes` 列。新增 API：`device.dispose`、`report.annual`、`export.json`、`attachment.list/upload/open/delete`、`reminder.config/list/create/cancel`。API 类型集中于 `src/types/api/phase11.ts`，所有业务参数由服务端再次校验。仅识别标题含保修/到期、类型为一次性、字段可映射的已有订阅模板，不自动添加模板。

所有用户查询按可信 OPENID 过滤，报表和导出完整分页读取。附件由云函数上传，本功能不使用客户端云存储直读写；云存储规则须保持私有（仅创建者和管理员可访问），元数据不得公开。定时入口校验运行环境注入的来源，不能相信客户端 event 自报定时来源。

## UI 设计

用途：本人整理设备凭证、处置与年度支出。方向：延续已验收的实用型资产台账；颜色沿用 `#1a73e8`、`#f8f9fa`、`#202124`、`#b06000`、`#d93025`，字体继承现有微信原生字体和 SCSS Token，不新增字体或图标依赖。

设备详情增加「设备工具」入口，附件、处置、提醒各用专页；数据页增加年报入口。年报左对齐年度标题、突出总支出、自绘月度条形图。全部页面支持加载、空、错误/权限、重试、保存中禁用、协议检查、onShow 刷新与过期响应丢弃。

## 隐私与安全先行评估

附件可能包含姓名、地址、序列号、金额；选择前说明只用于本人凭证管理，建议遮盖无关信息。不识别、不训练、不公开分享。存储于国内 CloudBase 至主动删除附件/设备或注销；云文件地址和内容不写日志、不导出。本机预览临时文件及时清理。

订阅只记录设备、计划日期、模板和任务状态，不采集手机号、不强制授权、不群发；可取消未发送任务，保修/状态变化取消旧计划。消息只含设备名称、保修日期和固定提示，不含序列号、价格和附件地址。以微信真实模板、用户授权及平台权限为准，不引入 AppSecret。

隐私政策升级至 1.1.0，显式重新同意后启用新增能力。日志仅输出固定错误码，不序列化 SDK 异常。平台隐私声明需与实际文件选择/订阅调用一致；未配置模板、存储权限或定时器时，不宣称平台链路已完成。
